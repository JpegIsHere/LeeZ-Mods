# LeeZ-Mods

A collection of LeeZ mods for **7 Days to Die**.

## Mods

### [LeezGrowLights](LeezGrowLights/)

Powered grow lights for 7 Days to Die V3.1.x with six tiers, 5x5 crop coverage, underground/artificial-sunlight support, and XML-configured growth multipliers.

Current development version: **0.5.1.0**.

See the project README for installation, verified behavior, build instructions, testing status and roadmap.

### [Leez Beans Mod](LeezBeansMod/)

Bean plant project for 7 Days to Die. Includes a lightweight editable bean-plant OBJ source mesh, material hints, external model research/attribution, and a scaffold for the future crop/block implementation.

Current development version: **0.1.0.0**.
