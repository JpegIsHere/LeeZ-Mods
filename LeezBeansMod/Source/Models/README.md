# Model source

## leez_bean_plant.obj

Original lightweight bean plant source mesh for **Leez Beans Mod**.

The mesh is intentionally simple so it can be edited, UV-mapped, textured, decimated or split into growth stages before being packaged for 7 Days to Die.

Material hints are in `leez_bean_plant.mtl`.

### Coordinate setup

- Units: meters
- Up axis: Y
- Ground/origin: approximately Y = 0
- Plant height: approximately 0.94 m

### Important

7 Days to Die does not use this OBJ directly as the final runtime model. Treat this as editable source geometry for the Unity asset-bundle step.
