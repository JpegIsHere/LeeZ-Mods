# LeezGrowLights v0.7.0.1 - V3.1

Official dev11 release for **7 Days to Die V3.1.0 b14**.

## Validated fixes

- Directly wired grow lights draw **0 W** while the lamp toggle is OFF.
- Switching the lamp ON restores its configured **10 W** electrical load.
- OFF-state power synchronization remains correct after save/reload initialization.
- The radial-menu **Color** command now has a visible built-in icon.
- The radial-menu **Brightness** command now has a visible built-in icon.
- Existing dev10 colour/brightness cycling, persistence, visual intensity, tier behaviour, crop coverage and powered-light switching remain intact.

These changes were live-tested in game before promotion to the official build.

## Known multiplayer limitation

Remote-client colour/brightness authoring and full dedicated-server visual synchronization remain future multiplayer work.
