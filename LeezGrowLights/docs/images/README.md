# Design images

`GrowLightExample.JPG` is retained as an early visual reference for the grow-light concept.

Two larger source screenshots (`Description.JPG` and `Blocks_XML_Screenshot.JPG`) are preserved in the local GitHub-ready archive produced during development but were not transferred through the GitHub connector because its binary payload limit would risk corrupting them. They are documentation/reference assets only and are not required to build or run the mod.
